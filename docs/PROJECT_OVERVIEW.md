# Project Overview

## Purpose
CyberShield AI is a comprehensive cybersecurity frontend application designed to provide users with a centralized dashboard for analyzing, simulating, and mitigating various cyber threats. The goal is to deliver an intuitive and premium user experience while housing multiple advanced security tools.

## Main Functionality
The application acts as a hub for six core cybersecurity capabilities:
1. **Screenshot Phishing Analyzer**: Analyzes screenshots for phishing indicators.
2. **Phishing Simulator**: Simulates phishing attacks for training.
3. **Smart URL Scanner**: Scans URLs for malicious content.
4. **QR Security Scanner**: Evaluates the safety of QR codes.
5. **Password Security Lab**: Assesses password strength against modern attacks.
6. **Security Command Center**: A global dashboard for threat intelligence.

## Technology Stack
- **Framework**: React 19 + Vite
- **Language**: JavaScript (JSX)
- **Styling**: Tailwind CSS + Custom CSS Variables
- **Routing**: React Router DOM (v7)
- **State/Context**: React Context API
- **Animations**: Framer Motion
- **Icons**: React Icons (Feather Icons)
- **Charts**: Recharts

## Current Frontend Scope
The current phase establishes the shared UI foundation. This includes the Landing page, Login experience, protected Dashboard layout (Sidebar, Topbar), shared UI components (Cards, Buttons, Inputs), and standard placeholder routes for the six core features. No backend or database is currently integrated, keeping the architecture purely frontend-focused for initial development.
